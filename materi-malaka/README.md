# Materi Malaka

Upload PDF, PPT/PPTX, DOC/DOCX, atau XLS/XLSX langsung ke folder ini. File akan muncul otomatis di Materi SPP > Materi Malaka.

Gunakan nama seperti 01-panduan-pembelajaran-malaka.pdf. Simpan langsung di folder ini, tanpa subfolder.
